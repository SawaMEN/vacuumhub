# Карта разработки VacuumHub

> Обновлено: 8 ноября 2026 г.  
> **Всего этапов: 6. Выполнено: 1. Осталось: 5.**  
> Текущий результат: локально протестирован MVP платформы; публикация файлов и развёртывание на VDS отслеживаются отдельно.

## Принципы

- Self-hosted: один VDS/VPS; Go API и статический веб-интерфейс, SQLite, Caddy, Docker Compose.
- Каталог роботов-пылесосов, озвучек и прошивок — без зависимости от стороннего сайта.
- До появления проверенного адаптера установка прошивки на устройство **не поддерживается**; скачивание файла не означает совместимость.
- Публикация файлов после модерации, фиксация источника и права на распространение.
- Изменения выполняются небольшими проверяемыми коммитами; состояние этапа обновляется в этом файле.

## Риски

1. Неверная идентификация модели может повредить устройство — нужна проверка `hardware_id` и ревизии.
2. SHA-256 — только контроль целостности; не проверяет права, безопасность и подлинность.
3. Для коммерческих прошивок и озвучек нужно право на распространение.
4. В начальном MVP один admin-токен: для широкого публичного доступа необходимо усиление защиты.
