# Библиотека озвучек — API и меры безопасности

Реализовано на этапе 3 (08.11.2026). Задача [#2](https://github.com/SawaMEN/vacuumhub/issues/2).

## Модель данных

Каждый asset `kind=voicepack` содержит: `model_slug`, `series_slug` (slug серии), `version`, `language`, `author`, `license`, `package_format`, `notes`, `sha256`. Необязательное аудиодемо хранится отдельно: `preview_storage_filename`, `preview_sha256`, `preview_size_bytes`, `preview_mime`. Путь и физическое имя демо никогда не возвращаются публичным API.

Серия однозначно задаётся сочетанием `(model_slug, series_slug, language)`. Запрещено дважды публиковать одинаковую `(model_slug, series_slug, language, version)`; разные версии одной серии остаются доступными. Старые записи после миграции не меняются: их поля серии пусты, и они не включаются в новую историю, пока не будут вручную перепубликованы с метаданными.

`license` — утверждение администратора о правах на публикацию. Оно **не подтверждается автоматически**. `SHA-256` подтверждает лишь совпадение данных, но не отсутствие вредоносного ПО. Администратор обязан проверить источник и право распространения до утверждения публикации.

## API

- `GET /api/v1/voicepacks?model=<model-slug>&q=<title>` — только опубликованные пакеты, вместе с метаданными, `has_preview` и `package_format`.
- `GET /api/v1/voicepacks/{id}/versions` — опубликованные версии одной серии, той же модели и языка. Неопубликованные записи скрыты.
- `GET /api/v1/assets/{id}/preview` — только опубликованное аудиодемо, поддерживаются HTTP Range запросы; MIME задаётся сервером после проверки сигнатуры файла.
- `GET /api/v1/assets/{id}/download` — исходный архив; не означает разрешение или возможность прошивки робота.
- `POST /api/v1/admin/assets` — `multipart/form-data`, требуются Bearer admin token, `kind=voicepack`, `model_slug`, `title`, `series_slug`, `version`, `language`, `author`, `license` и `file`. Можно прикрепить `preview` (WAV/OGG/MP3, до 8 МиБ).
- `PATCH /api/v1/admin/assets/{id}` — `{"status":"approved"}` или `{"status":"rejected"}`; сервер перед утверждением повторно сверяет SHA-256 и структуру архива, а также хеш демо.

## Допустимые контейнеры

Для новых голосовых пакетов допускаются ZIP и `.tar.gz`/`.tgz`. Проверяются: корректность контейнера, CRC/чтение ZIP-записей, необязательного `vacuumhub.json` (если присутствует, обязан точно соответствовать `model_slug`, `series_slug`, `version`, `language` из формы), относительные нормализованные пути без `..`, отсутствие символических и жёстких ссылок, не более 2000 записей, ограничения суммарного распакованного объёма (200 МиБ), размера записи (100 МиБ), а для ZIP — сжатия (не более 200:1). Пакеты `.pkg`, `.bin`, `.img` нельзя публиковать как озвучки до появления отдельного валидатора соответствующего формата.

Отсутствие манифеста допустимо для архивов сторонних производителей: оно требует ручной проверки модератором и не свидетельствует о совместимости.

Файлы не распаковываются в файловую систему, сценарии и код из пакетов не исполняются. Аудиодемо поддерживается только в отдельном файле с совпадающими расширением и сигнатурой. Медиафайл ограничен 8 МиБ. Защита не является полным анализатором вредоносных данных, не выполняет проверку внутренних форматов озвучек и не подтверждает совместимость с устройством.

## Пример загрузки

```bash
curl --fail-with-body -X POST "https://YOUR_DOMAIN/api/v1/admin/assets" \
  -H "Authorization: Bearer $ADMIN_API_TOKEN" \
  -F kind=voicepack -F model_slug=roborock-s5 \
  -F series_slug=s5-ru-classic -F version=1.0 -F language=ru \
  -F title='Русская озвучка' -F author='Автор' -F license='CC-BY-4.0' \
  -F file=@voice.zip -F preview=@demo.ogg
```

## Ограничения и следующие работы

Нет автоматической установки на физический робот, автоматической юридической проверки лицензии, транскодирования аудио, антивирусной проверки и верификации подписей производителя. Всё это относится к следующим этапам и отдельной экспертизе конкретных форматов/устройств. Публичная отдача аудио специально не требует admin token, поэтому при публикации демо становится доступно всем посетителям.
