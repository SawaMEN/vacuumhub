# VacuumHub

Самостоятельная Linux-платформа для каталога моделей роботов-пылесосов, библиотеки озвучек и архива прошивок.

**Установка полностью нативная:** готовый бинарный файл (со встроенным сайтом), служба systemd и SQLite. На VDS/VPS **не нужен Docker, Caddy, Node.js или компилятор Go**. Стандартный публичный доступ — **только HTTPS по IP-адресу либо HTTPS по домену**. Режима «локально / localhost» в установщике нет.

## Установить или обновить

Требуется Linux с запущенным systemd, архитектура **amd64** или **arm64**, права root и доступ к GitHub Releases. Для сертификата Let's Encrypt нужен свободный входящий TCP 80, для самой панели — выбранный TCP-порт (по умолчанию 8443).

```bash
curl -fsSL https://raw.githubusercontent.com/SawaMEN/vacuumhub/main/install.sh | sudo bash
```

В интерактивном меню выберите **1) Установить / обновить**, затем один из **двух** вариантов:

| Режим | Как открыть |
|---|---|
| **1) По IP** | `https://ПУБЛИЧНЫЙ_IP:8443/` |
| **2) По домену** | `https://vacuum.example.com:8443/` |

Порт можно изменить, включая 443, если он свободен. Не используйте localhost/127.0.0.1 — установщик не предлагает локальный режим.

Установщик позволяет выбрать сертификат HTTPS: Let's Encrypt, существующий PEM или самоподписанный. Для IP Let's Encrypt требуется **Certbot ≥5.3** и короткоживущий сертификат (примерно шесть дней); установлен systemd-таймер для регулярного продления. Самоподписанный сертификат **не доверен браузером по умолчанию**. При использовании Certbot проверьте, что TCP 80 не занят другой службой.

Создайте логин и пароль администратора при установке. Браузер запросит их перед открытием страницы `/admin.html`. Отдельный ввод токена в интерфейсе для нативной установки не требуется; технический `ADMIN_API_TOKEN` создаётся установщиком.

Установщик скачивает архив релиза для конкретной архитектуры, сверяет его с `SHA256SUMS` и не компилирует проект на VDS. Если готового релиза ещё нет, установка останавливается с понятным сообщением.

## Управление

```bash
sudo vacuumhub
```

Меню позволяет обновить VacuumHub, переключиться между IP и доменом, настроить сертификат, изменить логин/пароль, запускать/останавливать службу, просматривать журнал, создавать резервную копию, проверять восстановление и удалять приложение.

Доступны команды:

```bash
sudo vacuumhub status
sudo vacuumhub restart
sudo vacuumhub logs
sudo vacuumhub update
sudo vacuumhub configure
sudo vacuumhub credentials
sudo vacuumhub backup
sudo vacuumhub restore-test /var/backups/vacuumhub/ИМЯ.tar.gz
```

Файлы установки: `/opt/vacuumhub`; конфигурация и сертификаты: `/etc/vacuumhub`; база и архив: `/var/lib/vacuumhub`. Удаление по умолчанию **сохраняет данные**. Резервные копии нужно дополнительно шифровать и выносить за пределы VDS.

## Возможности платформы

- Каталог производителей, моделей и аппаратных ревизий, поиск и подтверждаемые источники идентификаторов.
- Озвучки: язык, автор, права, версии, аудиодемо, структурная проверка архивов.
- Прошивки: история, происхождение, SHA-256, Ed25519 по закреплённым ключам, ClamAV перед публикацией.
- Модерация, административный аудит, ограничения неверных входов и проверки состояния SQLite.
- Dry-run проверки перед потенциальной установкой. **Физическая прошивка робота отключена** до появления испытанных аппаратных адаптеров и восстановления.

## Разработка и статус

Проект включает шесть этапов: **4 завершены, 2 остаются частичными**. Этап 5 требует реальных аппаратных испытаний, этап 6 — приёмки на действующем VDS/VPS и настройки внешних резервных копий. Изменение системы установки само по себе не означает, что сервер уже развёрнут.
